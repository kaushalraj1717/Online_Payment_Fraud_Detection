#  Online Payment Fraud Detection using Machine Learning

##  Project Overview

As online transactions continue to grow rapidly, payment fraud has also become a major concern in digital banking and e-commerce platforms.  
This project focuses on detecting fraudulent online payment transactions using Machine Learning techniques.

The system analyzes transaction patterns and predicts whether a transaction is legitimate or fraudulent, helping improve payment security and reduce financial risks.

---

##  Features

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Fraud Detection using Machine Learning
- Data Visualization & Insights
- Model Training and Testing
- Fraud Prediction System
- Performance Evaluation

##  Model Performance

Different Machine Learning algorithms were trained and tested to compare their fraud detection performance.

| Machine Learning Model | Accuracy |
|------------------------|-----------|
| Logistic Regression | 94.8% |
| Decision Tree Classifier | 97.2% |
| Random Forest Classifier | 98.7% |
| XGBoost Classifier | 99.1% |

###  Best Performing Model

The **XGBoost Classifier** achieved the highest accuracy and performed best in identifying fraudulent transactions with minimal false predictions.

The comparison between multiple algorithms helped improve the reliability and effectiveness of the fraud detection system.
